# PET Library

This folder contains the first public AIPET plugin examples.

Each PET has a distinct personality and reaction style:

- [Observer Orb](./observer-orb/README.md): a floating sentinel that tracks, scans, and hardens when something feels wrong
- [Silent Monitor](./silent-monitor/README.md): a cold machine eye with minimal motion and quiet suspicion
- [Digital Ghost](./digital-ghost/README.md): a fragile spectral presence with glitchy emotional shifts
- [Data Cloud](./data-cloud/README.md): a polished sci-fi intelligence made of light, rings, and reactive energy

Use them as references, starting points, or direct copy bases for your own custom PET.
